# VolVis

在浏览器中交互查看和旋转三维体积渲染。

**[打开在线查看器](https://s-yuan137.github.io/volvis/)**

| 数据集 | 直接查看 | 文件大小 |
| --- | --- | --- |
| Clump | [打开 Clump](https://s-yuan137.github.io/volvis/Clump.html) | 41.7 MiB |
| 2890 · Cluster 3 | [打开 2890 · Cluster 3](https://s-yuan137.github.io/volvis/2890cluster3Core.html) | 45.8 MiB |

## 如何观看

1. 打开在线查看器，选择数据集。
2. 等待数据加载完成；文件较大，首次打开可能需要一些时间。
3. 拖动鼠标旋转，使用滚轮缩放，并通过页面中的控件调整显示效果。

浏览器需支持 WebGL 2 和 WebM 视频解码。首页只在选择模型后加载对应数据。

Clump 可直接在浏览器中查看。2890 · Cluster 3 还需从 jsDelivr 加载渲染组件，观看时需要能访问该服务。
